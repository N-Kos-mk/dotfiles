# rules

Claude に読ませるルール集。CLAUDE.md から `@rules/...` で参照する。

## 構成

| ディレクトリ | 用途 |
|---|---|
| `core/` | 言語・ツール非依存の共通ルール（設計方針、命名規則など） |
| `git/` | Git操作のルール（コミット規約など）※追加時に作成 |
| `python/` | Python固有のルール ※追加時に作成 |

## 新カテゴリの追加方法

1. `rules/<category>/` ディレクトリを作成
2. ルールファイル（.md）を追加
3. CLAUDE.md に参照を追記
4. `dotfiles` にコミット＆プッシュ
